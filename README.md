# 💰 Educa$h

> O RPG da sua vida financeira

## 📖 Sobre o Projeto

O **Educa$h** é uma plataforma web gamificada de educação financeira desenvolvida com o objetivo de auxiliar jovens e adultos na construção de hábitos financeiros saudáveis por meio de experiências interativas de aprendizagem.

A solução combina conceitos de **Educação Financeira**, **Gamificação**, **Interação Humano-Computador (IHC)** e **Engenharia de Software**, transformando o gerenciamento financeiro em uma jornada semelhante a um jogo RPG, onde o usuário evolui seu personagem à medida que aprende e aplica conceitos financeiros em seu cotidiano.

O projeto foi desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de **Análise e Desenvolvimento de Sistemas**.

---

# 🎯 Problema

O elevado índice de endividamento da população brasileira demonstra que o acesso a serviços financeiros não garante, por si só, o desenvolvimento de competências para a tomada de decisões econômicas conscientes.

Muitas plataformas financeiras apresentam dados complexos e pouco atrativos, dificultando o aprendizado e a criação de hábitos financeiros sustentáveis.

---

# 💡 Solução

O Educa$h utiliza recursos de gamificação para transformar a educação financeira em uma experiência interativa e motivadora.

A plataforma permite que os usuários:

* Aprendam conceitos financeiros através de módulos educativos;
* Registrem receitas e despesas;
* Acompanhem indicadores financeiros;
* Participem de desafios e missões;
* Evoluam um personagem virtual;
* Ganhem XP e moedas;
* Explorem um mapa interativo inspirado em jogos RPG;
* Simulem investimentos financeiros.

# 🏗️ Arquitetura

O sistema foi desenvolvido utilizando arquitetura baseada em componentes.

```text
Frontend (React.js)
        ↓
      API REST
        ↓
Backend (Node.js)
        ↓
Banco de Dados
```

Principais características:

* Arquitetura modular
* Componentização
* Atualização dinâmica via Virtual DOM
* Escalabilidade
* Manutenibilidade
